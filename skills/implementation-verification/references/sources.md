# Sources

Method identified, not incorporated. Reading these is not required to follow
the skill:

- Beck, *Test-Driven Development: By Example*: the discipline of an observed
  failing state before a claimed passing one.
- Fowler, *Refactoring*: changing structure under a validation path that is
  run, not assumed.
- Humble & Farley, *Continuous Delivery*: the deployment pipeline as the
  single authoritative definition of what "passing" means.
- Nygard, *Release It!*: failure states and boundaries as first-class subjects
  of verification rather than afterthoughts.
