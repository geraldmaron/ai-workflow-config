# Sources

Method identified, not incorporated. Reading these is not required to follow
the skill:

- Tufte, *The Visual Display of Quantitative Information*: the lie factor, and
  graphical integrity as a measurable property.
- Cleveland, *The Elements of Graphing Data*: which encodings readers decode
  accurately, and which ones flatter the author.
- Bringhurst, *The Elements of Typographic Style*: hierarchy, measure, and the
  grid as a system rather than a set of preferences.
- Muller-Brockmann, *Grid Systems in Graphic Design*: consistency across a
  sequence of surfaces.
- Web Content Accessibility Guidelines, W3C: contrast ratios and text
  alternatives as thresholds rather than opinions.
